# RÉSIVO — Design System

> [!NOTE]
> The single source of truth for the RÉSIVO design system is now maintained in [docs/DESIGN.md](docs/DESIGN.md).

Please refer to [`docs/DESIGN.md`](docs/DESIGN.md) for complete specifications, including:
- Brand assets, logo variants, and color palette tokens
- Typography rules (Outfit for display/headings, Inter for body/tabular data)
- Elevation, radii, and spatial scale
- Standard icon catalogue and guidelines (zero emojis, strict stroke geometry)
- Universal component contracts (StatusPills, Cards, PageHeader, Steppers, KeyValue, Modals, etc.)
- Desktop console & Web portal architectural guidelines
