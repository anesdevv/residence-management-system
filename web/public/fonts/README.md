# Self-hosted web fonts

Vendored font binaries for the student web portal. **No CDN** (see `docs/DESIGN.md`
§3 Typography). Nothing in this folder is hand-edited.

| File | Family | Weight | Style | Subset | Size |
|---|---|---|---|---|---|

| `outfit-600.woff2` | Outfit | 600 | normal | latin | 13.8 KB |
| `outfit-700.woff2` | Outfit | 700 | normal | latin | 13.7 KB |

## Source

| Family | npm package | Package version | Upstream release | Upstream project |
|---|---|---|---|---|
| Outfit | `@fontsource/outfit` | 5.3.0 | v15 | <https://github.com/Outfitio/Outfit-Fonts> |
| Inter | `@fontsource/inter` | 5.3.0 | v20 | <https://github.com/rsms/inter> |

The two packages are devDependencies of `web/` (they ship the raw `woff2` files);
the binaries sourced from google/fonts are the same upstream releases. Copied
verbatim from

```
web/node_modules/@fontsource/outfit/files/outfit-latin-<weight>-normal.woff2
web/node_modules/@fontsource/inter/files/inter-latin-<weight>-normal.woff2
```

Only the **latin, non-italic** subset is shipped: it covers `U+0000-00FF`, so the
accented Latin the portal needs (`É` in RÉSIVO, resident names, `ñ`, `ü`, …) is
included. Cyrillic/Greek/Vietnamese/`latin-ext` and all italics are dropped.

`@font-face` should declare (values as published by `@fontsource`):

```css
unicode-range: U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD;
font-display: swap;
```

## Regenerating

```powershell
# from the repo root; requires `npm install` to have run in web/
$map = @{
  'outfit-latin-500-normal.woff2' = 'outfit-500.woff2'
  'outfit-latin-600-normal.woff2' = 'outfit-600.woff2'
  'outfit-latin-700-normal.woff2' = 'outfit-700.woff2'
  'inter-latin-400-normal.woff2'  = 'inter-400.woff2'
  'inter-latin-500-normal.woff2'  = 'inter-500.woff2'
  'inter-latin-600-normal.woff2'  = 'inter-600.woff2'
}
foreach ($k in $map.Keys) {
  $fam = if ($k -like 'outfit*') { 'outfit' } else { 'inter' }
  Copy-Item "web/node_modules/@fontsource/$fam/files/$k" "web/public/fonts/$($map[$k])"
}
Copy-Item web/node_modules/@fontsource/outfit/LICENSE web/public/fonts/OFL-Outfit.txt
Copy-Item web/node_modules/@fontsource/inter/LICENSE web/public/fonts/OFL-Inter.txt
```
