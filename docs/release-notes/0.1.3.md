# RÉSIVO v0.1.3

## English

- Fixed a packaging issue where clicking sidebar navigation pages or **Settings** in the installed Windows app failed with `ModuleNotFoundError` for lazy-loaded modules (`desktop.app.ui.pages.*`).
- Bundled all `desktop.app.*` and `desktop.ui.*` submodules into `RESIVO.exe` and added automated bundle verification checks.

## Français

- Correction d'un problème d'empaquetage provoquant une erreur lors du clic sur les pages de navigation ou sur **Paramètres** dans l'application Windows installée (`ModuleNotFoundError` sur les modules chargés à la demande `desktop.app.ui.pages.*`).
- Inclusion et vérification automatisée de l'ensemble des sous-modules `desktop.app.*` et `desktop.ui.*` dans `RESIVO.exe`.
