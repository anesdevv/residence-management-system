# RÉSIVO v0.1.2

## English

- RÉSIVO can now check GitHub Releases for updates and install them in one flow.
- **Settings → Updates** shows the installed version, the latest release notes, download progress and a Cancel button.
- Every update is checked before it runs: HTTPS GitHub hosts only, expected file name, published SHA-256, exact size and a valid Windows installer header.
- A silent install closes RÉSIVO, updates it and reopens it, keeping your session, language, settings and data.
- Automatic checks run at most once every 24 hours; failures never block startup.
- Release builds now come from one version number and include `SHA256SUMS.txt`.

## Français

- RÉSIVO peut désormais rechercher les mises à jour sur GitHub Releases et les installer en une seule opération.
- **Paramètres → Mises à jour** affiche la version installée, les notes de version, la progression du téléchargement et un bouton Annuler.
- Chaque mise à jour est vérifiée avant son exécution : hôtes GitHub en HTTPS uniquement, nom de fichier attendu, SHA-256 publié, taille exacte et en-tête d'installateur Windows valide.
- Une installation silencieuse ferme RÉSIVO, le met à jour et le rouvre en conservant votre session, votre langue, vos paramètres et vos données.
- Les vérifications automatiques ont lieu au plus une fois toutes les 24 heures ; un échec ne bloque jamais le démarrage.
- Les versions publiées proviennent désormais d'un seul numéro de version et incluent `SHA256SUMS.txt`.
