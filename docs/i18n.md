# RÉSIVO — Internationalization (i18n) Architecture & Guide

RÉSIVO provides full bilingual support in **English (`en`)** and **French (`fr`)** across both the **Desktop Operator Console** (PySide6 / Qt 6) and the **Student Web Portal** (Astro 7 / Tailwind CSS v4).

---

## 1. Architectural Overview

```
                                  +------------------------------+
                                  |   Translation Catalogs       |
                                  |  - desktop/i18n/{en,fr}.json |
                                  |  - web/src/i18n/{en,fr}.json |
                                  +--------------+---------------+
                                                 |
                   +-----------------------------+-----------------------------+
                   |                                                           |
                   v                                                           v
+------------------------------------+                    +------------------------------------+
|       Desktop App (PySide6)        |                    |         Web Portal (Astro)         |
|  - Engine: desktop/i18n/__init__.py|                    |  - Helper: web/src/lib/i18n.ts     |
|  - Routing: t(key), tn(key, count) |                    |  - Routing: astro.config.mjs i18n  |
|  - Formatting: format_number/date  |                    |  - Middleware: resivo_locale cookie|
|  - Persistence: QSettings          |                    |  - Switcher: Header FR | EN toggle |
+------------------------------------+                    +------------------------------------+
```

### Guiding Principles
1. **Separation of Presentation and Data**:
   - Database enums (`report_status`, `request_status`, `student_gender`) remain English identifiers (`pending`, `active`, `rejected`, `in_progress`, `resolved`, `approved`, `male`, `female`).
   - Logging, RPC schemas, file paths, and backend payloads remain English.
   - All user-facing labels, tooltips, dialogs, banners, and placeholders route through the i18n layer.
2. **Default & Fallback Chain**:
   - Primary default is English (`en`).
   - If a translation key is missing in French, the engine falls back to English, then logs a warning and outputs the key leaf. It never crashes.
3. **Typography & Institutional Register**:
   - French translations follow Algerian administrative standards (formal "vous", non-breaking spaces `\u00A0` before high punctuation `: ; ? ! %`, curved apostrophes `’`, 24-hour time notation).
   - Invariant institutional terms: `RÉSIVO`, `Cité Universitaire`, `Direction des Œuvres Universitaires (DOU)`, `Wilaya`.

## 2. Desktop Console Localization (`desktop/i18n/`)

### Core API (`desktop/i18n/__init__.py`)
- `t(key: str, **params) -> str`: Semantic dot-notation string lookup with named parameter interpolation:
  ```python
  from i18n import t
  title = t("login.hero_title")
  welcome = t("overview.greeting_with_name", greeting="Bonjour", name="Amina")
  ```
- `tn(key: str, count: int, **params) -> str`: Pluralized string resolution adhering to CLDR plural rules:
  - **English**: `count == 1` uses `_one`, else `_other`.
  - **French**: `count in (0, 1)` uses `_one`, else `_other`.
  ```python
  from i18n import tn
  bed_str = tn("rooms.beds_available", count=free_beds, count_fmt=free_beds)
  ```
- `format_number(val, decimals=None)`: Localized thousand and decimal separators (e.g. `1 234,50` in FR vs `1,234.50` in EN).
- `format_percent(val)`: Localized percentage symbol with non-breaking space (e.g. `98,5 %` in FR vs `98.5%` in EN).
- `format_date(val, format="medium")`, `format_time(val)`: Localized calendar and 24-hour clock formatting.

### Language Selection & Persistence
- **Settings Page**: Located under **Settings → General** via a Language combobox. Changing the language records the selection in `QSettings("RESIVO", "StaffConsole")` key `general/language` and displays a banner with **"Restart now"** and **"Later"**.
- **Login Window**: A discreet toggle button (`Français | English`) is accessible directly in the form footer. Clicking it toggles `QSettings` and immediately updates all UI strings in the login window in-memory via `_retranslate_ui()`.
- **Safe Restart Protocol**: Clicking "Restart now" releases `app._instance_lock` (QLockFile), spawns a new detached process with `QProcess.startDetached(sys.executable, sys.argv[1:] + ["--restarted"])`, and exits the current process cleanly.

## 3. Web Student Portal Localization (`web/src/i18n/`)

### Core Helper (`web/src/lib/i18n.ts`)
Built directly on top of modern JavaScript `Intl` APIs with zero external dependencies:
- `t(locale, key, params)`
- `tn(locale, key, count, params)`
- `localizePath(locale, path)`: Automatically maps internal routes (e.g. `/dashboard` $\leftrightarrow$ `/fr/dashboard`).

### Routing & Middleware (`web/src/middleware.ts`)
- Configured via Astro built-in i18n:
  ```javascript
  // web/astro.config.mjs
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'fr'],
    routing: { prefixDefaultLocale: false },
  }
  ```
- Priority resolution order for active locale:
  1. URL path prefix (`/fr` or `/fr/...` $\rightarrow$ `fr`)
  2. Persistent cookie `resivo_locale` (`fr` or `en`)
  3. Browser `Accept-Language` header (if starts with `fr` $\rightarrow$ `fr`)
  4. Default: `en`
- The header language switcher toggles between English and French, stores the choice in `resivo_locale` (1-year max-age), and redirects to the equivalent localized path.

## 4. Maintenance & Review Kit

To allow administrative staff and human translators to review all strings without reading code:

### Exporting Catalogs to CSV
Run:
```powershell
python tools/i18n_export.py
```
Outputs `docs/i18n-review.csv` with columns:
`platform,namespace,key,en,fr`

### Importing Reviewed CSV
After editing `docs/i18n-review.csv`:
```powershell
python tools/i18n_import.py
```
Validates `{placeholder}` parity, checks against schema corruption, and regenerates `desktop/i18n/{en,fr}.json` and `web/src/i18n/{en,fr}.json`.

## 5. Automated Testing & Pseudo-Locale QA

### Pseudo-Locale UI Stress Testing
To visually verify that controls do not clip and that zero strings were left unextracted:
```powershell
$env:RESIVO_PSEUDO_LOCALE = "1"
python desktop/main.py
```
Expands text length by ~40% and adds accented glyphs (`[!! Àpplḯcȧtḯṓns !!]`) while preserving `{placeholder}` tokens.

### Running Test Suites
- Desktop i18n unit tests:
  ```powershell
  .\.venv\Scripts\pytest desktop/tests/test_i18n.py desktop/tests/test_i18n_catalogs.py -v
  ```
- Full desktop test suite:
  ```powershell
  .\.venv\Scripts\pytest desktop/tests/ -q
  ```
- Web portal test suite:
  ```powershell
  npm --prefix web test
  ```
